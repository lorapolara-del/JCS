# Опитування Masculine / Feminine Principles: онлайн-застосунок

Учасники відкривають лише посилання. Результат автоматично потрапляє на екран ведучого, діаграми оновлюються наживо.

## Розгортання на Render (безкоштовно, ~10 хвилин)

1. Створіть акаунт на https://github.com і новий **приватний** репозиторій (кнопка New).
2. У репозиторії натисніть **Add file → Upload files** і перетягніть усе з цієї папки (`server.js`, `package.json`, папку `public`, `.gitignore`, `README.md`). Натисніть Commit.
3. Створіть акаунт на https://render.com (можна увійти через GitHub).
4. **New → Web Service**, оберіть ваш репозиторій.
5. Налаштування: Runtime = **Node**, Build Command = `npm install`, Start Command = `node server.js`, Instance type = **Free**.
6. (Необов'язково) У розділі Environment додайте змінну `RESET_KEY` з вашим паролем. Тоді очистити кімнату зможе лише той, хто його знає.
7. Натисніть Create Web Service. Через кілька хвилин Render покаже адресу виду `https://назва.onrender.com`.

## Як користуватися

- **Ведучий** відкриває `https://назва.onrender.com/results`. Сторінка створює код кімнати і показує посилання для учасників. Адресу цієї сторінки збережіть, вона веде до тієї самої групи.
- **Учасники** відкривають посилання з цієї сторінки (воно виглядає як `https://назва.onrender.com/?room=abc123`), проходять опитування й бачать свої дві цифри. Результат надсилається в групу автоматично.
- Нова група: відкрийте `/results` без параметра, і створиться нова кімната. Стару можна очистити кнопкою Reset.
- Учасник, який проходить тест повторно з того самого браузера, замінює свій попередній результат, а не додається вдруге.

## Важливо

- Безкоштовний Render «засинає» після ~15 хвилин без запитів, і перше відкриття після паузи триває 30-60 секунд. Відкрийте посилання за кілька хвилин до заняття.
- Дані зберігаються у файлі на сервері. На безкоштовному плані вони можуть зникнути після перезапуску, тож це підходить для живих сесій, а не для архіву. Робіть скриншот результатів наприкінці заняття.
- Зберігаються лише код кімнати, випадковий ідентифікатор браузера та дві цифри. Імена й особисті дані не збираються.

## Локальний запуск (для перевірки)

`node server.js`, потім відкрийте http://localhost:3000 (потрібен Node 18+).
